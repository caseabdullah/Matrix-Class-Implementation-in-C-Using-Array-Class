# 🔢 Matrix Class Using Array Class | C++

### 📌 About the Project

This project implements a **Matrix Class using a custom Array Class** in C++, applying Object-Oriented Programming (OOP) concepts and class composition.

The `Matrix` class uses an `Array` object internally to store and manage matrix rows and columns.

The project focuses on implementing mathematical matrix operations, matrix property checking, submatrix manipulation, and dynamic memory management while building reusable and structured C++ classes.

### 🛠️ Technologies & Concepts

- **Language:** C++
- **OOP Concepts:**
  - Classes and Objects
  - Encapsulation
  - Composition (Has-A Relationship)
  - Constructors and Copy Constructor
  - Destructors
  - Dynamic Memory Allocation
  - Deep Copying
  - Const Correctness

### ⚙️ Implemented Features

**1. Matrix Management**

- Create matrices using specified rows and columns.
- Access and modify matrix elements.
- Display matrix elements.
- Resize matrices dynamically.
- Compare two matrices for equality.

**2. Basic Matrix Operations**

- **Addition:** Adds two matrices.
- **Subtraction:** Subtracts one matrix from another.
- **Multiplication:** Performs matrix multiplication.
- **Transpose:** Swaps rows and columns.

**3. Matrix Properties**

- **Identity Matrix:** Checks whether a matrix is an identity matrix.
- **Upper Triangular:** Checks whether all elements below the main diagonal are zero.
- **Lower Triangular:** Checks whether all elements above the main diagonal are zero.
- **Triangular:** Checks whether a matrix is upper or lower triangular.
- **Symmetric:** Checks whether a matrix equals its transpose.
- **Skew-Symmetric:** Checks whether its transpose equals its negative.

**4. Matrix Manipulation**

- **Slice:** Extracts a submatrix from specified boundaries.
- **Minor:** Creates a submatrix by excluding a particular row and column.
- **Trace:** Calculates the sum of main diagonal elements.
- **Anti-Trace:** Calculates the sum of anti-diagonal elements.

**5. Object Management**

- Default constructor.
- Parameterized constructor.
- Copy constructor.
- Destructor.
- Deep copy implementation.
- Constant and non-constant element access.

### 🧠 Key Learning Outcomes

- Understanding class composition through an Array object inside the Matrix class.
- Implementing mathematical matrix operations using custom classes.
- Managing two-dimensional data using dynamic memory allocation.
- Understanding deep copying and memory ownership.
- Applying constructors, copy constructors, and destructors.
- Practicing const correctness in C++.
- Strengthening problem-solving and Object-Oriented Programming skills.
